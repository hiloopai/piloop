# t9-piloop-bugs

The agents hunt ten state and ordering bugs in piloop at the task's pin, with no reports: the brief names only the
subsystems that hold them. The dev command is piloop's suite (`passed`, `failed`). A piloop arm's pool ranks on the
campaign's split instead (`rank.py`), its own held-out tests, which share none with the holdout: a green suite would
tie every correct candidate with the baseline. Results are reported on the holdout alone. Its headline is the six
open bugs, under a guard of the whole suite; the four closed bugs brought back are a secondary score (`reinjected`), as
their fixes are public upstream and a piloop arm's box carries an installed piloop that has them.
