## The archive

Agents leave notes, logs and outputs in the campaign's shared workspace. What a run can make again, such as samples
of the data and build outputs, goes in its checkout's `scratch/` instead: it is in no version and is deleted with the
checkout. The **archive** moves the finished parts of the workspace into the [CAS](#the-cas):

| When | What |
|---|---|
| An idea is done and none of its runs is open | The entries named after it: `idea12/`, `idea12-canary.log`. |
| A campaign stops and none of its agents is alive | Everything left in its workspace. |
| Never | `NOTES.md` and `research/` at the top of the workspace. |

The daemon removes the local copies 7 days later, or sooner while the disk has less than `[storage] min_free_gb` free.
`piloop restore` brings files back, and never overwrites a file:

```bash
piloop restore arch idea1/plots
```

```text
restored 1 file(s), 200.0 kB, into /tmp/pl-docs/home/projects/3/workspace; 0 already there
```

`piloop restore arch idea#12` restores one idea's files, and `piloop restore arch` everything. `piloop store status`
shows what is archived.

## The CAS

One content-addressed store, the **CAS**, serves every campaign of a `PILOOP_HOME`. It holds the archived files, the
agents' [sessions](/concepts/roles#sessions) and the workers' jobs. A blob is addressed by its BLAKE3 hash, so a file
is stored once. Nothing is deleted from it.

`[plugins.cas]` in `$PILOOP_HOME/config.toml` selects where the blobs go. The default, `disk`, keeps them in
`$PILOOP_HOME/store`. `cached` keeps a local cache over a remote store, such as a bucket:

```toml
[plugins.cas]
provider = "cached"
evict_after_days = 30      # drop local copies older than this
local_max_gb = 200         # and keep the local cache under this size
remote = { provider = "s3", url = "s3://my-bucket/piloop" }
```

| Command | What it does |
|---|---|
| `piloop store verify` | Checks that every archived blob is still there. |
| `piloop store evict` | Drops the local copies that the remote holds, now. |
| `piloop cas serve` | Serves the CAS to [workers on other machines](/guides/workers). |

S3 finds its credentials as boto3 does. `gcs` needs the `gcs` extra: `uv tool install --reinstall 'piloop[gcs]'`.
